# Sprechstunden (Aufzeichnungen von Vorlesungen und Sprechstunden)

Transkripte oder Notizen **aufgezeichneter Lehrveranstaltungen** — Sprechstunden,
Vorlesungen, Übungsstunden — als Markdown oder Text, eine Datei je Termin, mit Datum im
Namen (z. B. `Sprechstunde 2026-10-12.md`).

Der Skill holt hieraus zwei Dinge: die **Prüfungshinweise des Dozenten** („das frage ich",
„das frage ich nicht", „die Formel kriegen Sie") und **welche Aufgaben besprochen wurden**.
Ohne Alt- und Musterklausuren ist das die **höchste Gewichtung** — siehe
[`../README.md`](../README.md). Fachlich bleibt das `Skript` die Wahrheitsquelle; weicht der
Dozent davon ab, vermerkt der Skill beides.
